# Homebrew tap for SparkDown

Install SparkDown (Apple Silicon) with:

```bash
brew install --cask sparkdown/tap/sparkdown
```

SparkDown is ad-hoc signed (not notarized). On first launch macOS may block it: right-click the app and choose **Open**, or go to **System Settings → Privacy & Security → Open Anyway**.

Homepage: https://sparkdown.dev/
